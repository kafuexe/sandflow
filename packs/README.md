# Vendored packs

`base/` is a copy of [kafuexe/sandflow-base-boxes](https://github.com/kafuexe/sandflow-base-boxes), shipped inside Sandflow so the
base pack is there on first start even without internet. When online, Sandflow replaces it with the latest release.
Refresh it after a release of that repo (copy everything except `.git`, `.github` and `tools`).
